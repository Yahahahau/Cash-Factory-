# Stage progression

- **Coin target per stage** (unchanged formula): 50, 250, 300, 400, 550, 750; after that ×1.22 per stage (920, 1120, 1370, ...).
- **Coin value:** 1 + 0.65·(stage − 1).
- **Stage reward:**
  - cash = 30·n·(1 + 0.6·n) × Stage Bounty,
  - gems = 2 + ⌊n/2⌋ + ⌊Bounty/2⌋.

**New Run moved from stage 6 to stage 10.** Stages 7–9 are now part of every run, and they bring the content listed below.

| Stage | Theme | New in the run |
|---|---|---|
| 1 | Steel Works | Pistons, coin rate, capacity, rare chance |
| 2 | Tide Pool | Coin Polish. Parts: Piston Drive Bronze, Machine Frame Bronze |
| 3 | Neon Arcade | Stage Bounty, Auto Feeder. Coin Deck Bronze |
| 4 | Candy Works | Collector Tray Bronze, Piston Drive Silver |
| 5 | Bio Lab | Night Vault, Combo Keeper. Main Drive Bronze, Coin Deck Silver, Frame Silver |
| 6 | Sun Workshop | Golden Touch. Piston Drive Gold, Tray Silver |
| 7 | Steel Works (cycle) | Stage Resonance. Deck Gold, Drive Silver |
| 8 | Tide Pool | Piston Drive Platinum, Tray Gold, Frame Gold |
| 9 | Neon Arcade | Deck Platinum, Drive Gold |
| 10 | Candy Works | **New Run**. Piston Drive Crystal, Tray Platinum |
| 11–14 | ... | The remaining Platinum and Crystal tiers (long-term goals beyond New Run) |

Each stage keeps its own machine layout and visual theme, from the 3D overhaul: surface, lighting, back wall, and entrance and exit animations.

The **Stage Map** window (Start menu) lists all of this for the current run and marks the current stage. Stages are played in order: replaying an earlier stage would let a player farm cheap stage rewards, so the map is an overview rather than a selector.
