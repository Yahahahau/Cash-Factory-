## Suggested buying order

1. **Coin core (P0):** metal coin impacts and collects (CM-04, CM-05, CM-10..13) and the drop (CM-01). This is the sound of the game.
2. **Purchase and progression (P0):** UP-01, UP-02, UP-07.
3. **Window chrome (P0 / P1):** WIN-01 first, then the rest of the window family so they match.
4. **Flying Ball (P0):** FB-03, FB-04, FB-05, FB-07, FB-09.
5. **Machines (P0 / P1):** CM-15, CM-21, then the rest.
6. P1, then P2 only if time allows.
